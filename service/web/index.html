CAMADA 4

O navegador não permite abrir sockets TCP/UDP arbitrários. Abra o terminal na pasta do projeto e rode os comandos abaixo com este painel aberto. Os eventos aparecerão nos mesmos gráficos.

TCP · ROUND ROBIN :9090
python3 scripts/l4_client.py --protocol tcp --port 9090 --count 18
TCP · LEAST CONNECTIONS :9092
python3 scripts/l4_client.py --protocol tcp --port 9092 --count 24 --concurrency 12 --delay 1800
TCP · WEIGHTED 5:3:1 :9093
python3 scripts/l4_client.py --protocol tcp --port 9093 --count 90
UDP · ROUND ROBIN :9091
python3 scripts/l4_client.py --protocol udp --port 9091 --count 18

L4 atua sobre fluxos TCP e datagramas UDP. L7 atua sobre requisições HTTP. A porta 8080 é exclusiva dos testes HTTP; 9091 é UDP e as demais 909x são TCP.
